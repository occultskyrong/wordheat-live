# 中继私有部署配置

此目录已有 `.env.example`；各环境的私有 `.env` 被 Git 忽略，不能分发到 Web/Windows 或复制到其他项目。配置字段与权限见 [敏感信息规范](../../docs/security/20261025%20-%20词温项目%20-%20敏感信息与配置规范.md)。

通过获授权云控制台/CI 执行部署，禁止服务器 SSH；本次目录建立不代表中继已部署或平台已接通。
